# Praxis

Клинический симулятор диффдиагностики для студентов и молодых стоматологов.

## Скачать на Android

**[Praxis-v0.1.0.apk](https://github.com/beslan-spec/praxis/releases/download/v0.1.0/Praxis-v0.1.0.apk)** — 9 МБ, ставится без Play Store.

### Как установить

1. Скачайте APK по ссылке выше (лучше с телефона).
2. Если Android спросит разрешение — разрешите установку из этого приложения (Chrome / Файлы).
3. Откройте файл **Praxis-v0.1.0.apk** и нажмите «Установить».
4. На рабочем столе появится иконка **Praxis**.

Это отладочная сборка для теста, не из Google Play. Play Protect может предупредить — для этой версии это нормально.

## Что внутри

Очередь из восьми пациентов. Жалоба, осмотр, снимки, диффдиагноз, план, разбор. Прогресс пишется на устройство.

Ночной фон — луна в шапке.
